# 简历编排工具（在线版）

粘贴岗位 JD，自动给项目经历打分排序，实时预览并导出 Word / PDF。

在线地址：https://cixuy.github.io/resume-tool/

## 说明

这是一个单文件网页工具，纯前端运行，不需要后端。

本仓库只放工具本体，**不含任何个人信息**。首次使用请复制 `profile.example.js` 为 `profile.js` 并填入自己的信息，或直接在页面上手动填写表单。

完整版（含历史简历存档、各岗位导出示例）在私有仓库 `resume-builder`。

## 功能

- 六个岗位预设：Java 后端、AI Agent、C++ 工程师、服务器工程师、测试开发、Go 云原生
- 粘贴 JD 后按关键词给项目打分，分数可解释（会列出命中了哪些词）
- A4 单页预览，导出 Word（可在 Word 里继续编辑）或 PDF（浏览器打印）

## 匹配逻辑

```
得分 = 命中标签数 × 3 + 方向契合度 × 2
```

`tags` 是项目涉及的具体技术词，与 JD 文本做包含匹配；`direction` 是方向归属，JD 里某方向的词越多，该方向项目加分越多。

纯本地计算，不联网、不上传任何内容。
